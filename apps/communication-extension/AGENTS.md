# 项目协作约束

这是个人独立的 Chrome 外贸沟通辅助工具。

## 不可破坏的边界

- 不加入任何公司名称、公司 Logo、公司作者身份或公司专属域名。
- 不复制第三方发布包中的压缩代码、图标和私有接口。
- 不在源码、安装包或测试数据中写入真实 API Key。
- 默认本地运行、数据本地保存；联网功能必须由用户主动开启并配置。
- API Key 不得出现在数据导出文件中。
- 只申请当前功能必需的浏览器权限。

## 交付要求

- 修改后运行 `npm run check`。
- 发布前确认 `release/外贸开发插件-v<version>-chrome.zip` 可解压，且根目录含 `manifest.json`。
- 修改数据结构时递增 `schemaVersion` 并提供迁移逻辑。
- 修改用户可见功能时更新 `CHANGELOG.md`。
