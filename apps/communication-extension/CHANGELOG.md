# 更新记录

## 0.3.0 - 2026-09-08

- 数据结构升级到 schema 3，记录哪些客户字段由最近一次 Lydia 分级文件导入。
- 再次导入时允许更新或清空仍未被用户修改的 Lydia 字段，使工作台中的证据撤回能够同步到沟通环节。
- 用户在插件中手工修改过的姓名、企业、地区、邮箱或 WhatsApp 始终保留，并停止由 Lydia 自动管理。
- 分级摘要中的证据数量排除技术拒绝或人工拒绝的证据。
- 保留 schema 1/2 客户资料；旧版非空字段没有来源记录时默认按人工资料处理，不自动覆盖或删除。

## 0.2.0 - 2026-09-08

- 支持导入 Lydia 外贸工作台生成的客户分级 JSON。
- 客户资料增加工作邮箱、WhatsApp 和分级摘要。
- 选择已分级客户时自动载入原始询盘，方便继续生成人工审核的回复。
- 数据结构升级到 schema 2，并保留旧版客户、历史和人工备注。
- 增加清单、包版本和界面版本一致性检查。
- 安装包使用固定时间与排序打包，并验证重复构建 SHA-256 一致。

## 0.1.0 - 2026-09-07

- 建立个人独立项目和品牌边界。
- 支持 10 类外贸沟通场景识别。
- 支持三种上下文和三种语气的离线英文回复。
- 支持用户自带兼容 OpenAI 格式的接口。
- 支持客户资料、回复历史、本地持久化以及安全导入导出。
- 增加最小权限、自动测试、构建校验和可分享安装包。
