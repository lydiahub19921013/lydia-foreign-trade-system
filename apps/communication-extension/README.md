# 外贸开发插件

一个个人独立维护的 Chrome 外贸沟通辅助工具。它帮助外贸从业者识别客户来信所处阶段、生成专业英文回复，并把客户资料和沟通历史保存在本机。

经过真实客户调研，外贸客户更高优先级的需求是获客，包括已有询盘背调分级、海外公开线索与联系方式，以及海外人脉和信任路径。当前版本只覆盖客户开发与沟通环节，不冒充完整获客系统；研究记录和后续方向见 [docs/CUSTOMER_RESEARCH.md](docs/CUSTOMER_RESEARCH.md)。

本项目不代表、不隶属于任何公司，也不使用任何公司的名称、品牌资产、账号体系或专属服务。

## 当前版本能做什么

1. 识别询盘、报价、样品、议价、订单、付款、生产、运输、投诉、跟进 10 类场景。
2. 使用本地模板离线生成英文回复；也可由用户自行配置兼容 OpenAI 格式的服务。
3. 本地保存客户资料和回复历史，支持导出和导入；导出时自动排除 API Key。
4. 导入 Lydia 外贸工作台生成的客户分级 JSON，保留 A/B/C/D/HOLD、分数、询盘原文和下一步建议。
5. 重新导入 Lydia 文件时同步证据撤回：只更新仍由 Lydia 管理的字段，插件内人工修改不会被覆盖。

## 安装

### 开发者模式安装

1. 安装 Node.js 20 或更高版本。
2. 在项目目录运行 `npm run check`。
3. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择项目内的 `dist` 文件夹。
5. 点击浏览器工具栏里的扩展图标，侧边栏会打开。

### 发给体验用户

运行：

```bash
npm run package
```

安装包会生成到 `release/外贸开发插件-v0.3.0-chrome.zip`。体验用户解压后，按上面的开发者模式步骤加载解压目录。

## 使用方式

1. 粘贴客户英文消息，点击“识别场景”或直接“生成回复”。
2. 选择通用、行业背景或我的公司三种上下文。
3. 填写客户资料并保存。生成过的回复会进入本地历史记录。
4. 默认使用离线模板，不产生接口费用。需要 AI 时，在设置中填写自己的接口地址、模型和 API Key，并主动开启。
5. 如果已经在 Lydia 外贸工作台完成分级，可在“备份与恢复”中导入分级 JSON；选择客户时会带入原始询盘和开发建议。
6. 工作台驳回或修订证据后，再导入最新分级 JSON。插件会撤回未被手工修改的旧 Lydia 字段；销售人员已经修改的资料保持不变。

也可以在网页中选中一段客户消息，右键选择“发送到外贸开发插件”。

## 隐私与成本

- 客户资料、历史和设置默认保存在 Chrome 本机存储中。
- 离线模板不会上传数据，也不产生模型费用。
- 只有用户开启 AI 并点击生成时，当前消息和所选背景才会发送到用户配置的接口。
- API Key 仅存本机，不会进入导出文件。

完整说明见 [PRIVACY.md](PRIVACY.md)。

## Codex 复用 Skill

项目内同时保存了 `$foreign-trade-tool-builder` Skill。以后遇到外贸客户定制插件、桌面工具或手机应用时，可以调用它判断哪些业务逻辑可以复用、是否适合使用桌面 Harness，并按客户项目独立完成品牌、数据、测试和交付。

Skill 的权威副本位于 `codex-skill/foreign-trade-tool-builder`；本机通过 `~/.codex/skills/foreign-trade-tool-builder` 调用。
