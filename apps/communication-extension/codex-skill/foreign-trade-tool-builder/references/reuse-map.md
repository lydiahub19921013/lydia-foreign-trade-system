## 默认业务基线

- 用户真实调研表明外贸客户最关注获客：已有询盘背调分级、海外公开线索与联系方式、海外人脉和信任路径。完整记录见项目根 `docs/CUSTOMER_RESEARCH.md`。
- 场景：询盘、报价、样品、议价、订单、付款、生产、运输、投诉、跟进。
- 背景：通用、行业、当前产品或企业事实。仅把用户选择的背景送入生成过程。
- 输出：可编辑英文草稿，不自动发送，不自动承诺价格、交期、退款或认证。
- 数据：默认本机保存；API Key 只存在本机设置，导出时移除并关闭 AI 开关。
- 权限：永久权限保持最小；可选接口只在用户触发时申请具体域名访问。

## 每个客户必须重新确定

- 产品名称、所属主体和可用品牌资产。
- 目标平台、安装方式、更新方式和实际验收环境。
- 客户消息来源、字段、业务阶段和必须保留的历史数据。
- 使用哪家 AI 服务、费用由谁承担、哪些数据允许发送。
- 语言、语气、知识背景、禁说内容和需要人工确认的事实。
- 是一次性交付、付费定制、维护合同还是内部试用。

## 不直接复用

- 旧公司发布包或其中的压缩构建代码、图标、作者、接口、账号和付费逻辑。
- 任一真实客户消息、联系人、公司资料、API Key、日志或浏览器存储。
- Chrome 专属 UI 到手机或桌面环境的机械复制。
- 母版的 Git 历史到客户仓库；下游必须有自己的干净历史和远端。
