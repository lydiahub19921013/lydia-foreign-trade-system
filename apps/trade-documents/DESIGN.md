# 成交单证工作台视觉方向

对象是每天核对客户、产品、价格、箱数的外贸业务员。首页应立即呈现一张可以检查的单证，以及生成它的订单资料；单证切换是主要画面动作。

- 色彩：深海蓝 `#183745`（工作台框架），雾蓝 `#e6edf0`（桌面），纸白 `#fffefb`（单证），墨黑 `#1a2b32`（正文），印章橙 `#ac673d`（待审核），边线 `#bdccd1`（区隔）。
- 字体：中文界面使用系统苹方／无衬线；英文单证标题使用 Georgia，作为实际文件的标题而非营销大字；数字使用等宽数字特性，方便核对金额与箱数。
- 桌面布局：左侧固定宽度订单编辑区，右侧单证架和完整纸张预览。信息左对齐；金额右对齐。

```text
┌─ Lydia 单证台 ─────────────── 本机草稿 ────────────┐
│ 订单资料 / 产品 / 条款 │ 报价  PI  发票  装箱  合同  目录 │
│                       │ ┌──── 一张完整单证 ───────────┐ │
│ [客户和卖方]           │ │ 卖方 / 买方  编号 / 日期       │ │
│ [本次产品]             │ │ 产品行 / 数量 / 价格 / 合计    │ │
│ [条款和包装]           │ │ 条款 / 审核提示               │ │
│ [生成六份草稿]         │ └─────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

有记忆点的是“单证架”：六张文件以可切换的标签组织，每次切换保持同一笔订单上下文，纸张内容随文件类型变化。视觉取自办公桌上的真实单证，避免营销页面、同质卡片和假业务成绩。

自查：这套布局只适合需要逐项核对贸易文件的任务；示例订单明确标为内置示例，录屏时须填入当期真实业务材料。小屏改为上下排列，仍保留完整单证结构；不把纸张裁到只剩一行文字。
