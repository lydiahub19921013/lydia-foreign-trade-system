# 候选邮箱

此功能解决的是“已有联系人姓名和企业域名时，下一步应核查哪些邮箱”，不是承诺找到真实邮箱。

## 输入和处理

- 联系人英文名可选；只在浏览器中用于组合，不会发送给第三方。
- 企业域名必填；本机服务查询 DNS MX，必要时检查 A/AAAA 回退。
- 姓名候选与 `sales@`、`export@`、`info@` 等职能候选合计最多 10 个。
- 若当前工作台刚读取的官网页面公开列出完全相同的地址，会记录该来源。

## 状态边界

- `mx-found`：只说明企业域名配置了邮件路由。
- `address-fallback`：域名没有 MX 但有 A/AAAA，邮件能力仍不确定。
- `no-mail-route`：不允许把这些候选加入询盘。
- `inconclusive`：DNS 查询失败或超时，不能判断。
- 任何具体邮箱始终是 `candidate` 或 `inconclusive`，不会因为 MX 或命名模式变成 `verified`。

## 误操作保护

如果询盘已经有企业域名，候选邮箱必须使用同一域名；否则工作台会阻止保存。询盘没有域名时，人工保存候选可以填补该空字段，但不会覆盖已有客户资料。

系统不执行 SMTP 探测、不发送测试邮件、不批量外联。公开邮箱也不等于联系人同意接受营销。
