# 本机自动保存

## 保存在哪里

Lydia 工作台把规范化后的当前状态保存在浏览器 IndexedDB 中。默认启动地址是 `http://127.0.0.1:4173`，快照只属于这个浏览器资料和这个来源；工作台服务器不接收或写入客户状态。

自动保存包括：

- 询盘、Evidence、冻结分级、重复账户判断和开发活动；
- 跟进待办、当前阶段和转化统计所需的底层记录；
- 公开候选与搜索计划、GLEIF/官网候选证据、候选邮箱和信任路径；
- 当前筛选条件、研究表单和客户目标选择等必要界面状态。

不会保存：

- Exa 公开搜索确认和官网访问授权勾选；恢复后联网前必须再次确认；
- API Key、Token、密码、浏览器登录态或插件设置；
- 原始文件的本机绝对路径；
- 未列入快照白名单的未知字段。

## 保存与恢复

每次导入、证据审核、重复账户判断、开发活动、待办或研究结果发生变化后，工作台排队写入一个版本化快照。界面只有在 IndexedDB 事务真正完成后才显示“已自动保存”和时间；失败时会明确要求立即导出 JSON，不会把内存状态冒充已保存。

刷新页面或重新打开同一地址时，工作台会读取快照，重新规范化 Lead 并计算等级、重复候选、阶段、待办和转化统计。联网授权勾选始终恢复为关闭。

## 安全边界

- IndexedDB 是本机浏览器存储，不是云端数据库、跨设备同步或多人协作。
- 快照未由 Lydia 额外加密。同一操作系统账户、可访问该浏览器资料的人或恶意本机软件可能读取；共享电脑不应长期保存真实客户数据。
- `http://127.0.0.1:4173` 与 `http://localhost:4173` 是不同来源，浏览器不会自动共享快照；应始终使用启动命令显示的地址。
- 清除浏览器站点数据、重置浏览器资料或使用不持久的隐私模式，可能删除快照。
- IndexedDB 容量由浏览器决定。配额不足或存储不可用时，界面会报错；此时应立即导出 JSON。

## 备份与清除

本机自动保存解决“刷新丢数据”，不能替代备份。每次重要批次或交付前仍应使用“导出给沟通插件”保存 Lydia JSON，并放入用户自己的受控目录。

“清除本机数据”需要二次确认，只删除当前工作台的 IndexedDB 快照；不会删除已经导出的 JSON、外贸开发插件数据、源码仓库或 GitHub 内容。清除后页面重新载入并显示“尚无本机数据”。
