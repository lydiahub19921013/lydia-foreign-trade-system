# 本机自动保存

## 保存在哪里

Lydia 工作台把规范化后的状态按客户空间保存在浏览器 IndexedDB 中。默认启动地址是 `http://127.0.0.1:4173`，空间索引和各客户快照只属于这个浏览器资料和这个来源；工作台服务器不接收或写入客户状态。

自动保存包括：

- 询盘、Evidence、冻结分级、重复账户判断和开发活动；
- 已确认 CSV 的列映射核对记录；记录不包含预览样例值或被忽略列内容；
- 跟进待办、当前阶段和转化统计所需的底层记录；
- 公开候选与搜索计划、GLEIF/官网候选证据、候选邮箱和信任路径；
- 当前筛选条件、研究表单和客户目标选择等必要界面状态。

不会保存：

- Exa 公开搜索确认和官网访问授权勾选；恢复后联网前必须再次确认；
- API Key、Token、密码、浏览器登录态或插件设置；
- 白名单对象内部名称含 API Key、Secret、Token、Password、Authorization 或 Cookie 的字段；
- 原始文件的本机绝对路径；
- 未列入快照白名单的未知字段。

## 保存与恢复

每次导入、证据审核、重复账户判断、开发活动、待办或研究结果发生变化后，工作台排队写入当前客户空间的版本化快照。界面只有在 IndexedDB 事务真正完成后才显示客户空间名称、“已自动保存”和时间；失败时会明确要求立即导出 JSON，不会把内存状态冒充已保存，也不会继续切换客户。

刷新页面或重新打开同一地址时，工作台只读取当前客户空间的快照，重新规范化 Lead 并计算等级、重复候选、阶段、待办和转化统计。切换空间会先保存当前空间再重新载入目标空间；联网授权勾选始终恢复为关闭。v0.12 的旧单一快照会自动迁入第一个客户空间。

## 安全边界

- IndexedDB 是本机浏览器存储，不是云端数据库、跨设备同步或多人协作。
- 客户空间只隔离同一 Lydia 工作台中的本机快照，不提供登录、角色权限或服务端 tenant；详细边界见 [本机客户空间](./CUSTOMER_WORKSPACES.md)。
- 快照未由 Lydia 额外加密。同一操作系统账户、可访问该浏览器资料的人或恶意本机软件可能读取；共享电脑不应长期保存真实客户数据。
- `http://127.0.0.1:4173` 与 `http://localhost:4173` 是不同来源，浏览器不会自动共享快照；应始终使用启动命令显示的地址。
- 清除浏览器站点数据、重置浏览器资料或使用不持久的隐私模式，可能删除快照。
- IndexedDB 容量由浏览器决定。配额不足或存储不可用时，界面会报错；此时应立即导出 JSON。

## 备份与清除

本机自动保存解决“刷新丢数据”，不能替代备份。每次重要批次或交付前应点击“导出完整备份”，把当前空间的客户、活动和各研究模块状态一起保存到用户自己的受控目录。各模块的普通 Lydia JSON 仍用于把选定业务结果交给沟通插件或其他流程，不能视为完整灾备。

完整备份恢复时先验证格式、版本和快照，再创建一个新的客户空间；即使名称相同也不会覆盖现有空间。备份在浏览器本地读取，限制为 25 MB。恢复完成后应核对客户数量、研究结果和关系路径，再决定是否保留旧空间。

完整备份 JSON 未加密并可能包含真实客户资料；敏感命名字段过滤是减少误存风险，不是内容级密钥扫描，也不是加密。文件不得进入 Git 或公共分享渠道。

“清除当前客户数据”需要二次确认，只删除当前客户空间的 IndexedDB 快照并保留空间；“删除空间”会删除当前空间及其快照，但至少保留一个空间。两种操作都不会删除其他客户空间、已经导出的 JSON、外贸开发插件数据、源码仓库或 GitHub 内容。
