# 产品边界

> 本文描述当前 `v0.1.x` 沟通工具的范围。外贸客户的更高优先级真实需求是获客，详见 [CUSTOMER_RESEARCH.md](CUSTOMER_RESEARCH.md)；当前版本不能宣传为完整获客系统。

## 服务对象

需要高频处理英文客户消息，但不想把客户资料交给固定 SaaS 平台的外贸个人或小团队。

## 核心闭环

客户消息进入 → 判断沟通阶段 → 结合业务背景生成可编辑回复 → 保存客户与回复历史。

## 第一版只做三件事

1. 场景识别。
2. 英文回复生成。
3. 客户资料与历史留存。

## 暂不做

- CRM 团队协作、云同步、账号与付费体系。
- 自动群发、自动抓取联系人或绕过平台限制。
- 平台询盘批量导入、企业背调、客户分级和开发优先级。
- 海外公开线索搜索、联系方式证据和企业经营调查。
- 共同联系人、信任背书和熟人介绍关系管理。
- 对接任何公司专属接口或复用公司品牌资产。
- 宣称 AI 输出可直接替代业务人员审核。

## 成功标准

- 一条真实客户消息能在 60 秒内得到可编辑回复。
- 浏览器升级或插件覆盖安装后，本地客户资料仍然存在。
- 默认离线可用；用户不配置接口也能完成核心任务。
- 安装包通过自动校验，并能由非开发者按说明完成加载。
