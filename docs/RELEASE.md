# 发布流程

## 自动检查

在项目根目录运行：

```bash
npm run check
```

该命令会依次完成单元测试、构建、品牌与权限校验，并生成 ZIP 安装包和 SHA-256。

## 浏览器验收

1. 在 `chrome://extensions` 加载 `dist`。
2. 打开侧边栏，粘贴一条询价消息。
3. 确认能识别为“询盘”或“报价”，并生成可编辑英文回复。
4. 保存一名客户，关闭并重新打开侧边栏，确认资料仍存在。
5. 导出 JSON，确认文件中不含 API Key。
6. 覆盖加载新版本，确认旧客户资料仍存在。
7. 如启用 AI，确认浏览器只申请配置接口所在域名的权限。

## 对外分享

- 只分享 `release/` 中带明确版本号的 ZIP。
- 同时记录 ZIP 的 SHA-256，便于确认客户拿到的文件没有被替换。
- 第一阶段采用小范围体验交付，不承诺自动更新和长期在线服务。
