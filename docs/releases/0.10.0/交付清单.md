# Lydia 外贸系统 v0.10.0 交付清单

## 可运行能力

1. 工作台显示由渠道编号、登记号、企业域名、已验证工作邮箱或“公司名＋国家”触发的重复客户候选。
2. 使用者可以确认“同一客户”或“不同客户”，并必须填写判断原因。
3. 确认为同一客户时必须从两条记录中选择主账户；次账户进入 HOLD，但原始询盘、联系人、证据和备注不删除、不覆盖。
4. 已处理决定保留时间、原因、当时的匹配强度和触发理由，并可以通过“重新判断”撤销。
5. 次账户的匹配指纹继续归到主账户，能够发现同一企业后来进入的第三条询盘。
6. schema 3 JSON 保留主账户关系与追加式复核历史，并可安全导入外贸开发插件 v0.3.0。

启动与验证：

```bash
npm run workbench
npm run check
```

## 尚未作为正式能力交付

- 自动选择主账户、自动删除或自动拼接两个客户的字段。
- 基于机器学习的概率匹配模型；现有阈值尚未用真实历史询盘校准。
- 跨批次长期数据库和多用户主数据管理。
- Chrome 中从旧版插件原位升级到 v0.3.0 的人工安装验收。
