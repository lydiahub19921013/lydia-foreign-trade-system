# v0.10.0 变更记录

- Lead 数据结构升级到 schema 3，新增追加式重复客户复核历史。
- 重复客户候选新增“确认为同一客户”“不是同一客户”和“重新判断”。
- 同一客户决定要求人工指定主账户；次账户进入 HOLD，但原始询盘完整保留。
- 已处理决定从待办中移除，同时在可展开的审计区保留时间和原因。
- 次账户指纹可归入主账户继续参与第三条询盘的候选发现。
- 命令行输出同时包含待处理 `duplicateCandidates` 和已处理 `duplicateDecisions`。
- 虚构样例增加一条跨渠道同企业询盘，用于浏览器主路径回归。
- 调研并固定 Dedupe、Splink、GoldenMatch 版本和 MIT 许可证；只吸收设计原则，没有引入运行依赖或复制上游代码。

完整历史见仓库根目录 `CHANGELOG.md`。
