# Lydia 外贸系统 v0.11.0 交付清单

## 可运行能力

1. 导入询盘时冻结每个独立账户当时的 A/B/C/D/HOLD 等级、分数和时间，后续结果不反向改写基线。
2. 客户卡片可以记录已联系、收到回复、已报价、已寄样、收到订单、成交、流失、重新开发和备注。
3. 每次记录可以同时安排下一步和截止时间；待办可标记完成，原计划与完成记录都保留。
4. 工作台显示当前开发阶段、下一步、逾期状态，并可按阶段、有待办或已逾期筛选。
5. 按冻结等级统计已联系、已回复、已报价、已寄样和成交的数量与比例；人工确认的重复次记录不重复进入分母。
6. 错误开发记录通过带原因撤回，原记录和撤回事件都保留，阶段和统计按有效事件重新计算。
7. 不联系、受限市场和已归入主账户的次记录不能新增外联或跟进待办；入站事实仍可记录。
8. schema 4 JSON 保留开发基线、追加式活动、待办和统计，并继续兼容外贸开发插件 v0.3.0。

启动与验证：

```bash
npm run workbench
npm run check
```

## 尚未作为正式能力交付

- 浏览器自动持久化或多人数据库；当前长期保存依赖导出 JSON，并在下次继续时重新导入。
- 邮箱、WhatsApp 或平台消息自动回写为活动；当前结果必须人工确认后记录。
- 已用真实历史询盘校准的转化基准、成交概率或自动调权。
- 桌面安装包、跨设备同步和权限管理。
- Chrome 中从旧版插件原位升级到 v0.3.0 的人工安装验收。
