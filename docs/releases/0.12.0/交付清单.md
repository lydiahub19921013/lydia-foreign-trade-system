# Lydia 外贸系统 v0.12.0 交付清单

## 可运行能力

1. 工作台把客户、开发活动、公开候选、企业/官网证据、候选邮箱、信任路径和必要界面状态自动保存到当前浏览器 IndexedDB。
2. 客户导入、证据审核、重复账户判断、开发活动、待办、研究结果和筛选变化都会进入串行保存队列；界面在事务完成后才显示保存时间。
3. 刷新同一地址后自动恢复客户数量、冻结等级、追加式活动、待办、转化统计、5 类搜索计划、公开候选和信任路径。
4. 快照采用版本化格式和状态/界面双白名单；联网确认勾选、未知字段和潜在顶层密钥字段不写入。
5. 不可读取、未来版本或保存失败会显示明确错误，不静默冒充成功；用户仍可导出 JSON 备份。
6. “清除本机数据”有二次确认，只清除当前工作台快照，不影响导出文件、插件数据或 GitHub 仓库。
7. 页面明确说明：本机快照未加密、按浏览器资料和来源隔离，也不是云同步或多人数据库。

启动与验证：

```bash
npm run workbench
npm run check
```

## 尚未作为正式能力交付

- 跨浏览器、跨设备同步、多人协作、workspace/tenant 隔离和权限管理。
- 对 IndexedDB 客户数据的应用层加密或操作系统钥匙串管理。
- 浏览器站点数据被人工清理后的自动云恢复；重要批次仍需导出 JSON。
- Chrome 隐私模式、配额耗尽和浏览器崩溃场景的真实宿主回归；错误分支已有模块测试与失败关闭设计。
- Chrome 中从旧版沟通插件原位升级到 v0.3.0 的人工安装验收。
- 用 20–50 条脱敏真实询盘完成的分级效果校准。
