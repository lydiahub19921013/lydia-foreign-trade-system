# Lydia 外贸系统 v0.13.0 交付清单

## 可运行能力

1. 不同客户使用独立的本机客户空间；页面只加载当前空间的询盘、Evidence、开发记录、公开候选、企业/官网研究、候选邮箱和信任路径。
2. 支持新建、重命名、切换、清空和删除空间；切换前先完成当前空间保存，保存失败时停止切换。
3. 清空只删除当前空间的数据并保留空间；删除会移除当前空间及其快照，且至少保留一个空间。
4. v0.12 的旧单一 `current` 快照首次启动时自动迁入“我的客户 1”，迁移成功后才删除旧键。
5. 所有 JSON 导出增加 `lydia-workspace-reference`，文件名包含客户空间名称，便于人工核对归属。
6. 带 Lydia 空间标记的 JSON 如果与当前空间编号和名称都不一致，导入会失败关闭，不会覆盖当前客户资料。
7. 页面和文档明确说明：本机客户空间不是登录权限、应用层加密、云同步、协同编辑或 SaaS 多租户。

启动与验证：

```bash
npm run workbench
npm run check
```

## 尚未作为正式能力交付

- 云端登录、角色权限、逐请求 tenant 授权、服务端加密、审计和跨设备恢复。
- 同一客户空间的多人或多页面并发合并；当前应一次只在一个页面编辑同一空间。
- CSV 和没有 Lydia 空间标记的旧 JSON 的自动归属识别；导入前仍需人工核对顶部客户空间。
- Chrome/Edge 隐私模式、配额耗尽、浏览器崩溃和真实旧快照迁移的目标宿主回归；旧快照迁移已有自动测试。
- Chrome 中从旧版沟通插件原位升级到 v0.3.0 的人工安装验收。
- 用 20–50 条脱敏真实询盘完成的分级效果校准。
