# v0.13.0 变更记录

- 新增版本化客户空间索引和按空间分区的 IndexedDB 快照键。
- 新增客户空间的新建、重命名、保存后切换、按范围清空和删除界面。
- 新增 v0.12 单快照到首个客户空间的保守迁移。
- 新增带客户空间标记的 JSON 导出和包含空间名称的文件名。
- 新增跨客户 Lydia JSON 导入门禁；空间编号或名称至少一项一致才能继续。
- 新增空间索引净化、名称/编号约束、重复名称拒绝和最多 50 个空间限制。
- 新增客户空间使用与安全边界文档，并同步 Lydia Skill 和 W09 规则。

完整历史见仓库根目录 `CHANGELOG.md`。
