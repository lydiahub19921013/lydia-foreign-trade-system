# Lydia 外贸系统 v0.14.0 交付清单

## 可运行能力

1. 点击“导出完整备份”可把当前客户空间的客户、开发活动、公开候选、研究结果、候选邮箱、信任路径和必要界面状态写入一个版本化 JSON。
2. 点击“恢复完整备份”只在本机浏览器读取文件，并始终创建新客户空间；不会覆盖当前空间或同名空间。
3. 同名备份依次恢复为“原名称 · 恢复”“原名称 · 恢复 2”，便于先核对再人工清理旧空间。
4. 完整备份导入限制为 25 MB，拒绝错误格式、无效版本和来自未来版本的快照。
5. 快照继续使用状态与界面白名单，并递归剔除名称含 API Key、Secret、Token、Password、Authorization 或 Cookie 的嵌套字段。
6. 仓库提供完全虚构的 `examples/workspace-backup.sample.json`，用于无真实客户信息的恢复演练和回归测试。
7. 页面和文档明确区分：普通业务 JSON 用于模块间传递，完整空间备份用于灾备与迁移；二者都未加密。

启动与验证：

```bash
npm run workbench
npm run check
```

## 尚未作为正式能力交付

- 云端备份、自动跨设备同步、登录、角色权限、服务端 tenant 隔离、应用层加密和多人协作。
- 备份正文中的内容级秘密识别；当前只过滤白名单外状态与敏感命名字段，不能代替人工检查和加密存储。
- Codex 本机浏览器宿主中的真实文件落盘事件和通过文件选择器重新导入；本轮已验证按钮、状态和模块级完整往返，但未上传本地文件。
- Chrome/Edge 隐私模式、配额耗尽、浏览器崩溃、关闭重开和多页面并发的目标宿主回归。
- Chrome 中从旧版沟通插件原位升级到 v0.3.0 的人工安装验收。
- 用 20–50 条脱敏真实询盘完成的分级效果校准。
