# Lydia 外贸系统 v0.15.0 交付清单

## 可运行能力

1. CSV 文件选择后先在当前浏览器打开字段核对窗口，不立即改动当前客户空间。
2. 核对窗口逐列显示原表头、最多两个本机样例值、建议 Lydia 字段和识别状态；使用者可以改映射或忽略该列。
3. 未识别列、重复目标字段、行宽异常和关键资料缺失会在导入前提示；空白或重复表头、未闭合引号、无数据行和无可用业务字段会阻止导入。
4. 只有点击“确认映射并导入”后才生成客户记录；取消或按 Esc 不改变现有数据。
5. 确认结果保存为版本化 `lydia-csv-import-audit`，只记录原列名、目标字段、核对时间、数量与告警，不复制弹窗样例值或被忽略列的单元格内容。
6. 虚构询盘样例经过同一核对主路径，可用于不接触真实客户文件的演练和回归测试。

启动与验证：

```bash
npm run workbench
npm run check
```

## 尚未作为正式能力交付

- 阿里巴巴、中国制造网当前真实导出文件的字段兼容性；本轮没有使用真实渠道文件。
- XLSX 导入；当前只支持 CSV。
- 命令行交互式字段核对；命令行仍使用固定别名映射。
- 自动理解陌生字段的业务含义；最终映射仍需使用者核对。
- 登录、统一收费权益、云端同步、角色权限、服务端 tenant 隔离和多人协作。
- 用 20–50 条脱敏历史询盘完成的分级效果校准。
