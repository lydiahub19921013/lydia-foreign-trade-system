# v0.15.0 变更记录

- CSV 导入改为“先核对、再写入”，取消核对不会改变当前客户空间。
- 新增逐列原表头、本机样例、建议字段、手工改映射和明确忽略能力。
- 新增未识别列、重复目标、行宽异常和关键字段缺失告警。
- 新增空白/重复表头、未闭合引号、无数据和无有效业务字段的失败关闭。
- 新增版本化 `lydia-csv-import-review` 与 `lydia-csv-import-audit` schema 1。
- 导入审计随分级结果和本机空间保存，但不保留样例值或被忽略列内容。
- 虚构样例改走与真实 CSV 相同的浏览器核对主路径。

完整历史见仓库根目录 `CHANGELOG.md`。
