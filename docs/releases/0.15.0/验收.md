# Lydia 外贸系统 v0.15.0 验收

验收日期：2026-09-08  
环境：macOS 26.5.2、Node.js v22.23.0、Codex 本机浏览器

## 已通过

- 系统自动测试 123 项通过，新增覆盖 CSV 结构错误、映射报告、手工改映射、重复目标、核对审计和敏感样例不落审计记录。
- 外贸开发插件自动测试 24 项通过；v0.3.0 安装包没有变化，SHA-256 继续为 `5893d2e26f4e2c33574b04badb949df6e8a124d67a92729c8ec3b1b07e0c3799`。
- 180 个文本文件完成禁用品牌和常见密钥扫描；`git diff --check` 与 JavaScript 语法检查通过。
- 浏览器使用完全虚构的内置样例验证了打开核对、修改一列为忽略、取消不写入、重新打开确认导入、核对记录随 IndexedDB 恢复。
- 确认后状态显示已核对 33 列映射；刷新恢复后仍能看到原导入的核对记录。
- 核对窗口在桌面宽度下可见标题、映射列表、告警、取消和确认操作，没有明显遮挡或溢出。
- 所有浏览器 QA 和仓库样例只使用保留域名和虚构名称，没有发送真实客户、联系人、关系或开发活动。

## 尚未通过，不能扩大表述

- 本轮浏览器 QA 只使用虚构内置样例，没有通过文件选择器上传真实阿里巴巴或中国制造网导出文件，因此不能声称已经适配两个平台的全部当前字段。
- 第一次导入真实渠道文件仍须人工检查所有有值列，并抽查至少 5 行关键字段；界面允许纠正映射，但不能自动理解每个陌生表头的业务语义。
- 只支持 CSV，不支持 XLSX；命令行导入仍使用固定别名映射，没有交互式核对窗口。
- `lydia-csv-import-audit` 保存原表头、目标字段、时间、数量和告警，不保存样例值或被忽略列内容；它不是原始文件备份。
- 本机客户空间没有登录、统一收费权益、角色权限、服务端 tenant 授权、应用层加密或云同步，不能称为 SaaS 权限系统。
- 尚无 20–50 条脱敏历史询盘和真实结果，不能声称评分已经预测成交。
- 没有在 Chrome 中人工执行旧版插件到 v0.3.0 的原位升级。

因此当前结论是“Lydia 已能在浏览器本机让使用者核对 CSV 原列与 Lydia 字段，并在确认后留下最小化审计记录”，不是“已经自动兼容所有渠道文件或具备统一账号权限”。
