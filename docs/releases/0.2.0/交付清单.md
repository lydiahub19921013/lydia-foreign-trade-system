# Lydia 外贸系统 v0.2.0 交付清单

## 可运行产物

- 本地询盘工作台：在仓库根目录运行 `npm run workbench`，打开 `http://127.0.0.1:4173`。
- 命令行分级：`npm run qualify -- <询盘.csv> --channel <渠道> --output <结果.json>`。
- Chrome 插件包：`apps/communication-extension/release/外贸开发插件-v0.2.0-chrome.zip`。
- 插件母版包：`/Users/macmini/Documents/ChatGPT/我的口播视频/outputs/foreign-trade-development-plugin/release/外贸开发插件-v0.2.0-chrome.zip`。

## 主路径

1. 在工作台选择自动、阿里巴巴或中国制造网。
2. 导入 CSV/JSON，查看 A/B/C/D/HOLD、证据、缺失项和重复候选。
3. 导出 `Lydia-客户分级-日期.json`。
4. 在外贸开发插件“备份与恢复”中导入分级 JSON。
5. 选择客户，载入询盘原文，生成并人工审核英文回复。

## 未交付为正式能力

- 阿里巴巴/中国制造网真实账号导出文件尚未验收，当前只覆盖常见中英文字段。
- 未自动抓取海外社媒、搜索引擎或 WhatsApp。
- 未接入真实客户通讯录、CRM 或关系图。
- 工作台目前需要 Node.js，不是双击安装的桌面应用。
