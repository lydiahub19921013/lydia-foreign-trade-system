# Lydia 外贸系统 v0.3.0 交付清单

## 可运行能力

- 询盘：CSV/JSON 导入、证据分级、重复候选、导出给外贸开发插件。
- 企业：输入法定名称和可选司法辖区，查询 GLEIF 并导出带来源的身份核验证据。
- 人脉：导入自有关系 CSV/JSON，排除拒绝路径，查看排序理由并导出候选路径。
- 沟通：继续使用 `apps/communication-extension/release/外贸开发插件-v0.2.0-chrome.zip` 人工审核回复。

启动命令：

```bash
npm run workbench
```

完整验证命令：

```bash
npm run check
```

## 未交付为正式能力

- 海外社媒账号或个人联系方式的批量抓取。
- 通用工商/信用数据库覆盖、邮箱可达性保证或 WhatsApp 号码确认。
- 自动发送邮件、WhatsApp 或熟人引荐消息。
- GLEIF 结果自动合并、真实关系图命中率和真实成交结果校准。
- 双击安装的桌面应用及其升级/回滚机制。
