# Lydia 外贸系统 v0.3.0 验收

验收日期：2026-09-08  
环境：macOS 26.5.2、Node.js v22.23.0、Codex 本机浏览器

## 已通过

- 系统自动测试 27 项通过，覆盖企业身份映射、固定 GLEIF 接口、服务错误隔离、关系数据导入、拒绝路径排除和既有询盘闭环。
- 外贸开发插件自动测试 22 项通过；插件包仍可重复构建，SHA-256 未变化。
- 90 个文本文件完成禁用品牌与常见密钥扫描，Lydia Skill 校验通过。
- 浏览器实际查询公开测试名称 `Apple Inc.`：GLEIF 返回 24 条可能记录，页面展示前 5 条并区分 `ISSUED` 与 `LAPSED`。
- 第一条记录显示 LEI、法定名称、辖区、登记编号、法定/总部地址、更新时间和直接来源链接。
- 浏览器实际载入虚构关系样例：3 条输入中排除 1 条 `declined`，其余按 95、54 分排序，并显示原因、同意状态和人工下一步。
- 工作台清楚披露查询时发送的字段；询盘正文、联系人和关系文件不会发送给 GLEIF。
- 页面在桌面尺寸下完成视觉检查，企业卡片、关系卡片和状态提示可见且无明显布局断裂。

## 尚未通过，不能扩大表述

- GLEIF 只覆盖拥有 LEI 的法律实体；没搜到不能推断企业不存在。
- LEI 不是信用、付款能力、采购意愿或成交概率证明。
- 查询结果尚未提供“人工确认后一键并入客户档案”的操作。
- 尚未用 Lydia 或客户的真实授权关系数据验收字段适配和路径有效率。
- 尚未在正式 Chrome 扩展环境完成插件覆盖安装，也没有用真实渠道导出校准评分。

因此当前结论是“公开企业身份核验和本地信任路径最小闭环可试用”，不是“完整海外征信、联系人发现或成交预测系统”。
