# Lydia 外贸系统 v0.4.0 交付清单

## 可运行能力

1. 导入已有询盘，查看可解释分级和缺失证据。
2. 通过 GLEIF 查询法律实体身份，人工确认后加入询盘。
3. 输入一张公开/已授权官网页面，提取候选联系与经营证据，人工确认后加入询盘。
4. 导入自有/授权关系数据，排序可能的熟人介绍路径并排除拒绝记录。
5. 导出更新后的 Lydia 客户分级，在外贸开发插件中继续人工沟通。

启动与验证：

```bash
npm run workbench
npm run check
```

## 未交付为正式能力

- 动态网页浏览器渲染、整站抓取或批量运行。
- 自动合并冲突字段、自动发送消息或未经关系人同意的介绍。
- 正式客户环境的桌面安装包、升级和回滚。
