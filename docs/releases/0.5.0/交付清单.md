# Lydia 外贸系统 v0.5.0 交付清单

## 可运行能力

1. 在工作台导入询盘并选择目标客户。
2. 输入联系人英文名（可选）和企业域名或官网。
3. 生成不超过 10 个姓名/职能邮箱候选，同时检查域名邮件路由。
4. 查看官网公开、MX、A/AAAA 回退或无邮件路由等证据状态。
5. 人工选择候选加入询盘；企业域名冲突会阻止保存。
6. 导出候选结果，或导出更新后的 Lydia 客户分级给外贸开发插件。

启动与验证：

```bash
npm run workbench
npm run check
```

## 未交付为正式能力

- SMTP 邮箱探测、catch-all 判断或第三方验证 API。
- 批量联系人搜索、社媒抓取或自动外联。
- 候选邮箱的真实送达率和回复率校准。
- 客户安装环境的桌面安装包及升级回滚。
