# Lydia 外贸系统 v0.5.0 验收

验收日期：2026-09-08  
环境：macOS 26.5.2、Node.js v22.23.0、Codex 本机浏览器

## 已通过

- 系统自动测试 47 项通过，新增覆盖候选组合上限、域名规范化、MX、空 MX、A/AAAA 回退、DNS 失败、具体邮箱状态和企业域名错配门禁。
- 外贸开发插件自动测试 22 项通过，确定性安装包 SHA-256 保持不变。
- 107 个文本文件完成禁用品牌与常见密钥扫描，Lydia Skill 校验通过。
- 使用虚构联系人 `Alex Morgan` 和公开企业域名 `apple.com` 完成实机 DNS 查询，生成 10 个有限候选并显示“域名存在 MX”。
- 页面明确显示：0 个候选被当前官网页面公开列出，具体邮箱仍未验证。
- 尝试把 `apple.com` 候选加入已有 `northstar.example` 的虚构询盘时，系统正确阻止并显示两个冲突域名。
- 候选列表、状态标签、导出入口和域名冲突错误完成桌面尺寸视觉检查。
- 联系人姓名只在浏览器组合；服务器接口只收到企业域名并执行 DNS，不运行 SMTP 或发送消息。

## 尚未通过，不能扩大表述

- 候选地址没有经过邮箱服务器、授权验证 API 或收件人确认，不能表述为“准确邮箱”或“可投递邮箱”。
- MX 只证明域名配置了邮件路由；catch-all、离职、别名和邮箱命名差异仍会造成误判。
- 官网公开列出只证明观察到该页面内容，不等于当前可用或同意接受营销。
- 尚未在真实授权客户样本上统计候选命中率、退信率和合规触达结果。
- 系统不会自动发送测试邮件、营销邮件或 WhatsApp。

因此当前结论是“候选邮箱补证和误操作保护可试用”，不是“邮箱验证服务”。
