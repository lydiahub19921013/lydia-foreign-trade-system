# Lydia 外贸系统 v0.6.0 交付清单

## 可运行能力

1. 输入产品、目标市场、买家类型和应用场景，生成 5 类公开候选搜索方向。
2. 明确确认数据去向后，通过本机 agent-reach 可选调用 Exa，最多返回 5 个候选。
3. 把搜索标题/摘要保持为未核查候选，统一执行 49 分上限和来源门禁。
4. 导入或导出 Lydia 候选 JSON/CSV，并按企业域名去重。
5. 把候选送到现有官网单页补证；确认原页后才可加入主动开发队列。
6. 继续使用 GLEIF、官网证据、候选邮箱、关系路径和沟通插件补全开发动作。

启动与验证：

```bash
npm run workbench
npm run check
```
