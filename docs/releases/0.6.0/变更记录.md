# v0.6.0 变更记录

- 增加产品/市场/买家类型/应用场景驱动的公开候选搜索计划。
- 增加本机 agent-reach / Exa 可选适配器，使用进程参数调用而非 Shell 拼接，并限制查询与返回长度。
- 增加 PublicProspect 模型、五维解释分、域名去重和 CSV/JSON 导入。
- 搜索候选默认封顶 49 分；没有公开来源、相关信号或原页核查时不能成为 shortlist/primary。
- 候选经官网补证后可转为 `Public research` 开发记录，但不会被标成主动询盘。
- 静态服务只允许工作台、浏览器核心代码和虚构样例目录，阻止读取 `.git` 或仓库文档。
- 示例扫描扩大到全部 `examples` 文件，禁止非保留示例邮箱和网址。
- 保留所借鉴 MIT 项目的许可证与固定版本说明；AGPL/GPL 或高平台风险项目未引入。

完整历史见仓库根目录 `CHANGELOG.md`。
