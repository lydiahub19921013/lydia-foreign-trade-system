# Lydia 外贸系统 v0.6.0 验收

验收日期：2026-09-08
环境：macOS 26.5.2、Node.js v22.23.0、Codex 本机浏览器

## 已通过

- 系统自动测试 61 项通过，覆盖搜索计划、49 分上限、原页门禁、导入、域名去重、Exa 解析/失败隔离/长度限制和静态文件边界。
- 外贸开发插件自动测试 22 项通过，确定性安装包 SHA-256 保持不变。
- 119 个文本文件完成禁用品牌与常见密钥扫描；所有示例文件只使用保留示例域名；Lydia Skill 校验通过。
- 浏览器生成 5 个不同目的的搜索方向；未确认 Exa 数据去向时正确阻止搜索。
- 本机 agent-reach / Exa 实搜返回 5 个公开候选，全部显示“搜索候选，未核查原页”和“候选分 · 上限 49”。
- 第三方摘要在适配器限制到 2,000 字符、界面限制到 700 字符，避免异常长响应拖垮页面。
- 候选来源可一键带入官网补证；实测读取 1 张公开页面形成 5 条候选证据和 3 条公开联系线索。
- 未读取原页前不能加入开发队列；完成原页确认后，记录以 `Public research` 加入，并明确提示它不是主动询盘。
- 本机服务对 `.git/config` 和仓库 `README.md` 返回 403，仅允许工作台必需的静态资源和虚构样例。

## 尚未通过，不能扩大表述

- 搜索命中不等于采购需求，原页自述也不等于独立工商或信用证明。
- 当前五维权重来自方法研究，尚未用 Lydia 的真实产品和成交结果校准。
- 尚未统计不同搜索方向的有效企业率、可联系率、回复率、报价率和成交率。
- 系统不登录社媒、不抓私人资料、不自动发送邮件或 WhatsApp。

因此当前结论是“公开候选发现与补证闭环可试用”，不是“全自动精准获客”。
