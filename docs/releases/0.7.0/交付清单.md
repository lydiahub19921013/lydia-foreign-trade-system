# Lydia 外贸系统 v0.7.0 交付清单

## 可运行能力

1. 在官网证据区选择“只读取这一页”或“整理官网档案（最多5页）”。
2. 官网档案从使用者确认的页面出发，只发现同站的联系、企业介绍、工厂/能力、法定信息和产品/应用页面。
3. 页面调度先覆盖不同证据用途，再考虑同类补充页。
4. 汇总公开邮箱、电话、WhatsApp、地址和工厂自述，同时让每条 Evidence 保留具体来源页面。
5. 将档案人工确认后加入已有询盘，或把已完成原页补证的公开候选加入开发队列。
6. 单页失败时停止；补充页失败时保留已经取得的证据并单独记录失败数量。

启动与验证：

```bash
npm run workbench
npm run check
```

## 未交付为正式能力

- 无边界整站抓取、登录后页面、验证码或付费内容。
- 官网自述的自动事实认证、独立验厂或企业信用判断。
- 官网公开联系方式的营销同意或具体邮箱可投递性。
- 客户安装环境的桌面安装包及升级回滚。
