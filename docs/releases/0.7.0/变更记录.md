# v0.7.0 变更记录

- 增加企业官网档案模式，最多读取 5 张同站公开页面。
- 新增 Contact、About/Company、Factory/Manufacturing、Imprint/Legal、Products/Applications 等高价值页面识别。
- 页面调度优先覆盖不同证据用途，避免多个 Contact 子页占满读取额度。
- 汇总多页联系方式、地址和工厂自述，Evidence 仍保留逐页来源。
- 补充页面失败不会丢弃已成功取得的证据；根页面失败时关闭流程。
- 过滤 `@2x/@3x` 资源名和图片/脚本扩展名，避免网页素材误识别为邮箱。
- 保留原有单页模式，使用者可以按风险和目标选择读取范围。

完整历史见仓库根目录 `CHANGELOG.md`。
