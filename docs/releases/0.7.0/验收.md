# Lydia 外贸系统 v0.7.0 验收

验收日期：2026-09-08
环境：macOS 26.5.2、Node.js v22.23.0、Codex 本机浏览器

## 已通过

- 系统自动测试 68 项通过，新增覆盖同站高价值链接识别、5页上限、证据类型多样性、逐页来源、部分失败和根页失败。
- 外贸开发插件自动测试 22 项通过，确定性安装包 SHA-256 保持不变。
- 126 个文本文件完成禁用品牌、常见密钥和真实样例网址扫描；Lydia Skill 校验通过。
- 使用一个公开测试网站完成实机档案：读取 5 页，分别覆盖使用者指定页面、联系方式、企业介绍、工厂/能力和产品/应用。
- 实机结果形成 25 条候选证据和 6 条公开联系线索；没有把测试结果、真实联系方式或网页快照提交到仓库。
- 首轮实测发现图片资源名被识别为邮箱；修正后同一网站复验不再出现该误报，并新增回归测试。
- 浏览器同时显示单页与档案两个入口、读取页清单、每页证据数、候选状态和数据边界说明。
- 全部证据仍为 `candidate`，没有把官网自述升级成工商、信用、验厂或营销同意事实。

## 尚未通过，不能扩大表述

- 不同国家、语言和前端框架的网站导航结构仍可能导致漏页。
- 页面没有相关链接不等于企业没有联系方式、地址或工厂。
- 真实外贸产品的候选有效率、联系率和成交率尚未校准。
- 系统不登录社媒、不抓私人资料、不自动发送邮件或 WhatsApp。

因此当前结论是“受控的企业官网档案补证可试用”，不是“完整企业数据库”或“自动背调结论”。
