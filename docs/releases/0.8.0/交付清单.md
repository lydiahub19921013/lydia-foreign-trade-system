# Lydia 外贸系统 v0.8.0 交付清单

## 可运行能力

1. 官网单页或档案读取完成后，所有候选证据默认保持未选择状态。
2. 使用者逐条勾选要保留的企业名称、官网、地址、工厂信息、邮箱、电话或 WhatsApp。
3. 系统只把所选 Evidence 及其派生字段写入询盘或开发队列，未选择的内容不进入客户档案。
4. 所选 Evidence 记录人工接受决定和选择时间，但原有 `candidate` 状态不会自动升级为 `verified`。
5. 向已有询盘写入官网证据前校验企业域名；同一主域及子域允许，不同公司域名强制阻止。
6. 写入时只填补空字段，不覆盖已有人工资料；每条证据继续保留具体来源页面。

启动与验证：

```bash
npm run workbench
npm run check
```

## 未交付为正式能力

- 已入档证据的驳回、修订历史和字段自动回滚。
- 官网候选内容的独立事实认证、邮箱可投递性或营销同意判断。
- 跨公司主体、集团品牌或共用平台域名的自动归属判断。
- 客户安装环境的桌面安装包及升级回滚。
