# v0.8.0 变更记录

- 官网候选证据改为默认不入档，必须由使用者逐条勾选。
- 新增统一的 Evidence 选择转换，只从所选证据派生企业和联系字段。
- 为所选证据保存 `review.decision=accepted`、选择时间和用途说明，同时保留原有验证状态。
- 新增企业域名一致性门禁：同一主域及子域允许，不同公司域名阻止写入。
- 公开候选转开发队列时可写入所选邮箱、电话和 WhatsApp，不再只补企业字段。
- 客户档案展示“人工已选”，让人工取舍与事实验证清楚分开。
- 补充空选择、精确选择、人工决定时间、子域匹配和跨公司阻止等自动测试。

完整历史见仓库根目录 `CHANGELOG.md`。
