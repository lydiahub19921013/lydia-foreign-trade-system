# Lydia 外贸系统 v0.8.0 验收

验收日期：2026-09-08
环境：macOS 26.5.2、Node.js v22.23.0、Codex 本机浏览器

## 已通过

- 系统自动测试 71 项通过，覆盖精确选择、空选择拒绝、人工决定记录、候选状态保留、子域匹配和跨公司域名阻止。
- 外贸开发插件自动测试 22 项通过，确定性安装包 SHA-256 保持不变。
- 132 个文本文件完成禁用品牌和常见密钥扫描；Lydia Skill 校验通过。
- 使用一个公开测试网站生成 25 条候选证据；默认 0 条被选中，两个保存入口均不可用。
- 勾选一条后保存入口启用；未勾选内容不会进入客户档案。
- 把该网站证据写入另一公司域名的虚构询盘时被强制阻止。
- 对没有企业域名的虚构人工线索勾选两条后，系统只加入这两条官网证据，原有人工邮箱未被覆盖。
- 入档证据显示“`candidate · 人工已选`”，没有因人工保留而误标为已核实。
- 实测结果、公开网站联系方式和网页快照均未提交到仓库。

## 尚未通过，不能扩大表述

- 人工选择只表示保留候选，不证明官网内容真实、联系人身份、邮箱可投递或存在营销同意。
- 集团子公司、品牌站点、经销商站点和共用平台域名仍需人工判断，不应仅凭域名关系自动归属。
- 已入档证据尚不能通过完整修订日志自动撤回派生字段。
- 真实外贸产品的候选有效率、联系率和成交率尚未用 30—50 条真实样本校准。

因此当前结论是“候选证据可控入档并阻止明显错配”，不是“官网信息已自动核实”。
