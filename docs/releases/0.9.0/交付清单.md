# Lydia 外贸系统 v0.9.0 交付清单

## 可运行能力

1. 已入档证据可以人工驳回、恢复或修订，并要求填写原因。
2. 每次人工决定都保留时间、原因及修订前后值，导出后仍可审计。
3. 系统记录证据填入了哪个客户字段；证据被驳回时，只撤回仍等于系统填充值的字段。
4. 人工后来改过的客户资料不会被证据驳回、恢复或再次导入覆盖。
5. 被驳回的证据不再参与客户分级和重复线索判断。
6. 公开候选进入开发队列时只写入人工选中的内容，不再夹带未选择的网页标题、地址或跳转网址。
7. 外贸开发插件升级到 v0.3.0，能够同步 Lydia 字段撤回，同时保留插件内的人工修改。

启动与验证：

```bash
npm run workbench
npm run check
```

## 尚未作为正式能力交付

- 真实渠道字段适配的长期稳定性，需要用各平台最新导出样本持续校准。
- 官网候选内容的独立事实认证、邮箱可投递性或营销同意判断。
- 真实外贸产品的候选有效率、联系率和成交率结论。
- Chrome 里从旧版插件原位升级到 v0.3.0 的人工安装验收。
