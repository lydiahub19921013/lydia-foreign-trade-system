# v0.9.0 变更记录

- 新增 Evidence 驳回、恢复和修订流程，并保存完整人工决定历史。
- 新增字段来源记录，明确每条证据填入的客户字段和值。
- 驳回证据时安全撤回未被人工改动的派生字段；恢复和修订同样不覆盖人工资料。
- 被人工驳回的证据不再参与客户分级和重复线索识别。
- 客户数据模型升级到 schema 2，JSON 导出和再次导入会保留字段来源及审核历史。
- 修复公开候选转开发队列时可能带入未选择网页字段的问题。
- 非网址来源编号改为普通文字，避免生成失效的“查看来源”链接。
- 外贸开发插件升级到 v0.3.0，新增 Lydia 管理字段记录和安全撤回同步。
- 补充证据生命周期、字段回滚、人工修改保护、导出往返和未选字段泄漏回归测试。

完整历史见仓库根目录 `CHANGELOG.md`。
