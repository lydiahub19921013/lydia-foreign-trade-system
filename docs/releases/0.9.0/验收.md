# Lydia 外贸系统 v0.9.0 验收

验收日期：2026-09-08  
环境：macOS 26.5.2、Node.js v22.23.0、Codex 本机浏览器

## 已通过

- 系统自动测试 82 项通过，覆盖证据驳回、恢复、修订、人工字段保护、审核历史、字段来源和 JSON 往返。
- 外贸开发插件自动测试 24 项通过，覆盖 Lydia 字段撤回同步及插件人工修改保护。
- 插件 v0.3.0 两个发布位置的安装包 SHA-256 都是 `5893d2e26f4e2c33574b04badb949df6e8a124d67a92729c8ec3b1b07e0c3799`，可重复构建验证通过。
- 139 个文本文件完成禁用品牌和常见密钥扫描；Lydia Skill 校验通过。
- 用虚构询盘完成浏览器流程：初始 71 分；驳回邮箱证据后安全撤回 1 个字段并降为 69 分；恢复后回到 71 分；修订邮箱后客户字段同步更新。
- 同一条证据保留 3 次人工操作历史，修订记录含前值、后值、时间和原因。
- 浏览器导出的 schema 2 JSON 已检查字段来源和完整审核历史；核心层导出再导入测试通过。
- 非网址渠道编号在页面显示为普通来源文字，不再生成错误链接。
- 未选择的网站字段不会进入开发队列，跨公司核验页面仍被阻止。
- 浏览器 QA 只使用虚构数据；导出验证文件已移到废纸篓，未提交仓库。

## 尚未通过，不能扩大表述

- 当前控制接口不能替浏览器文件选择器完成自动回传，因此没有声称“浏览器文件导入界面已自动回归”；数据往返由核心自动测试验证。
- 没有在 Chrome 中人工执行从旧版插件原位升级到 v0.3.0，不能声称客户升级安装已验证。
- 人工接受只表示决定保留该证据，不等于企业、联系人或采购意愿已获得独立认证。
- 真实外贸产品的候选有效率、联系率和成交率仍需用 30—50 条真实样本校准。

因此当前结论是“证据可以被追溯地纠错，并安全同步字段变化”，不是“系统已经自动证明所有客户资料真实”。
