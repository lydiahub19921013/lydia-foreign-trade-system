# 企业邮箱域名 DNS 检查

此模块只查询企业域名的 MX 记录；没有 MX 时再检查 A/AAAA 回退。它不会连接邮件服务器、发送测试邮件或判断个人邮箱是否存在。

状态含义：

- `mx-found`：域名配置了邮件路由；只把 `mail-domain` 证据标为已核实。
- `address-fallback`：没有 MX，但存在 A/AAAA；按协议可能回退，结论为不确定。
- `no-mail-route`：域名不存在、返回空 MX，或没有任何邮件路由；候选邮箱应拒绝。
- `inconclusive`：DNS 超时或服务失败，不能下结论。

任何具体地址如 `alex@example.com` 都仍是候选，除非另有官网公开页面、经授权的验证服务和联系人身份等证据。公开列出也不等于同意接收营销邮件。
