# 公开官网单页证据采集

此模块只读取使用者主动提供的一张公开或已授权网页，不执行搜索引擎抓取、不登录、不绕过验证码、不遍历整站。

## 安全边界

- 只支持 HTTP/HTTPS 标准端口；解析并拒绝本机、内网和保留地址。为兼容 Clash 等代理，只在“正常域名经 DNS 解析”的情况下接受 `198.18.0.0/15` 合成地址，直接输入该网段仍会拒绝。
- 最多跟随 3 次同站跳转，拒绝跳到其他域名。
- 只接收 HTML/纯文本，页面上限 1 MB，请求 12 秒超时。
- 只保留标题、JSON-LD 地址、公开邮箱/电话/WhatsApp 和工厂描述片段，不保存整页内容。
- 所有官网结果一律是 `candidate`；官网自述不能替代工商登记、邮箱可达性或独立验厂证据。
- 公开联系方式不等于当事人同意接受营销信息，系统不会自动发信或发送 WhatsApp。

实现由 Lydia 独立编写，沿用本仓库“外部提取器必须转换为 Evidence”的接口思想，没有复制 Crawl4AI 或其他项目代码。
