# 信任与熟人引荐路径

## 数据前提

只处理 Lydia/客户自己拥有、主动提供或明确授权的通讯录、CRM、合作经历和关系记录。公开“同公司/同校”只能作为可能关系，不等于认识或愿意背书。

## 流程

1. 确认目标联系人和潜在关系人身份。
2. 记录关系强度、最近联系、共同公司/行业/教育经历及证据。
3. 排除已拒绝参与的人；没有证据的路径最高只能作为候选。
4. 首先向关系人说明目的、对方是谁、希望如何介绍并取得同意。
5. 由关系人自己决定是否介绍和如何措辞；系统不冒用其名字。
6. 记录介绍结果和后续信号，用于改进路径判断。

## 输出

给出候选路径、证据、同意状态和下一步，不承诺一定能介绍或成交。

## 当前工具入口

运行 `npm run workbench`，在“信任路径”中导入 Lydia/客户自有 CSV 或 JSON。字段说明见仓库的 `docs/RELATIONSHIP_IMPORTS.md`。

- 文件只在浏览器中解析；规范化后的候选路径会进入当前浏览器的本机快照，不上传到工作台服务器。
- `declined` 会在排序前排除。
- 没有证据编号的候选最高 49 分。
- 导出结果只提供“先征得谁同意”的人工下一步，不自动联系任何人。
- 本机快照未加密。共享电脑或切换客户前，应先导出到受控位置，再清除当前工作台数据。
